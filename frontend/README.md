# Faromid — Next.js + React + Tailwind CSS v4

این نسخه بر اساس فایل اصلی `faromid-nextjs(3).zip` بازسازی شده است. هدف، حفظ کامل فایل‌های تصویری و SVG اصلی و اصلاح ساختار فرانت‌اند است.

## اجرا

```bash
npm ci
npm run dev
```

سایت در `http://localhost:3000` اجرا می‌شود.

## بررسی قبل از Deploy

```bash
npm run verify:design-free
npm run verify:assets
npm run verify:source
npm run lint
npm run build
```

`verify:assets` با SHA256 صحت تک‌تک ۸۳ فایل تصویری/SVG نسخه آپلودشده را تأیید می‌کند.

## تغییرات مهم

- صفحه اصلی با **چیدمان دو ستونی دقیق مرجع تصویری 1056×558** بازسازی شده: عکس محصول سمت راست، پس‌زمینه تیره سمت چپ، طرح هندسی اصلی، Navbar شناور و یک کارت کوچک Melamine MDF. هیچ ShapeWaves یا `vgpu` استفاده نمی‌شود.
- هیچ متن تبلیغاتی جدیدی به ابتدای سایت افزوده نشده است.
- Navbar و Footer مشترک، منوهای دسترس‌پذیر و بدون هم‌پوشانی.
- Carousel محصولات با Scroll Snap، پشتیبانی از لمس/کیبورد و کنترل‌های مستقل.
- کارت‌های محصول و Hoverهای ملایم بدون پس‌زمینه قرمز ناگهانی.
- صفحه تماس شامل اطلاعات کارخانه/شوروم، فرم Mailto و تصویر نقشه اصلی با لینک مسیریابی است.
- سایر بخش‌ها و صفحات از Flexbox/Grid استفاده می‌کنند. برای حفظ نمای دقیق بنر Home در دسکتاپ، فقط اجزای همان بنر با **موقعیت نسبی درصدی** چیده شده‌اند؛ در موبایل ساختار عمودی جداگانه‌ای دارد. هیچ JSON طراحی یا Artboard مفسری در زمان اجرا وجود ندارد.
- فایل‌های SVG و تصاویر اصلی بدون کوچک‌ترین تغییر بایتی نگهداری شده‌اند.

## نکته اتصال فرم

فرم‌های تماس، همکاری و نمایندگی **ایمیل را باز می‌کنند**؛ ارسال مستقیم پیام به سرور یا دیتابیس هنوز پیاده‌سازی نشده است.

## ساختار

```
src/app/                  # مسیرهای Next.js
src/components/layout/    # Header, Footer, Shell مشترک
src/components/pages/     # صفحات مستقل
src/components/sections/  # بخش‌های تکرارپذیر صفحه‌ها
src/components/ui/        # Carousel, Product Card, Container
src/lib/                  # داده محصول و آدرس تصاویر موجود
public/assets/            # 83 فایل اصلی بدون ویرایش
scripts/                  # بررسی استقلال طراحی، مراجع فایل و SHA256
```

گزارش جزئیات در `REDESIGN_REPORT.md` قرار دارد.

جزئیات تطبیق صفحه اصلی با اسکرین‌شات در `HOME_DESIGN_FIX.md` ثبت شده است.
