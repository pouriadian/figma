# بازسازی دقیق Hero صفحه اصلی Faromid

## مبنا

- سورس پروژه: `faromid-reverted-modern-responsive.zip` (نسخه بازگشتی قبلی).
- مرجع بصری: اسکرین‌شات ارسال‌شده با ابعاد **1056 × 558**.
- سایر صفحات و امکانات قبلی بدون بازطراحی مجدد باقی ماندند.

## تغییرات

- **Header صفحه اصلی** به صورت لایه‌ای روی بنر قرار می‌گیرد، نه یک نوار چسبیده بالای عکس. در دسکتاپ همه ۹ لینک مطابق مرجع روی زمینه سفید نیمه‌شفاف نمایش داده می‌شوند؛ نسخه موبایل منوی بازشونده مستقل دارد.
- تصویر اصلی MDF در سمت **راست** و زمینه `#0d0d0d` در سمت **چپ** قرار گرفته‌اند. این ساختار جایگزین عکس تیره تمام‌صفحه نسخه قبلی شده است.
- نقش `hero-stripes.svg` در نیمه چپ، متن فارسی دوخطی با همان عبارت مرجع، دو گوشه قرمز و کارت کوچک **Melamine MDF / 183*280** احیا شدند.
- بنر از متن CTA/دکمه اضافی خالی است؛ کارت محصول تنها لینک کوچک محصول روی خود تصویر است.
- در دسکتاپ موقعیت‌ها **به نسبت درصد از مرجع 1728 × 915** محاسبه می‌شوند تا در عرض‌های مختلف هم‌تناسب بمانند. در موبایل تصویر و بخش تیره عمودی می‌شوند تا متن و منو خوانا باشند.
- حرکت CSS بسیار ظریف است و هنگام `prefers-reduced-motion` قطع می‌شود. خبری از WebGPU یا ShapeWaves نیست.

## تغییرات فایل‌ها

- `src/components/sections/home-hero.tsx`
- `src/components/layout/site-header.tsx`
- `src/components/layout/site-shell.tsx` (ایجاد مرجع موقعیت برای منوی Overlay در صفحه اصلی)
- `src/app/globals.css`

## تمامیت تصاویر

هیچ فایل SVG یا تصویر اصلی ویرایش نشده است؛ `npm run verify:assets` هر **۸۳ فایل** را با اثرانگشت SHA256 ثبت‌شده در پروژه بررسی می‌کند.

## اعتبارسنجی

- انجام شده: تطبیق هندسی دستی و خروجی مرورگر برای بنر در عرض 1056 پیکسل (شبیه‌سازی ساختار CSS؛ نه Build واقعی Next.js)، پارس کد TSX، بررسی Import و SHA256.
- نیازمند اجرا روی محیط دارای NPM: `npm ci`, `npm run lint`, `npm run build` و تست تعاملی واقعی دسکتاپ/موبایل.

> نسخه Desktop بنر برای وفاداری بصری عمداً از CSS percentage positioning استفاده می‌کند؛ سایر بخش‌ها همچنان کامپوننتی و Responsive هستند.
