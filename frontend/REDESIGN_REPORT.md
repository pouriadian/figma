# گزارش بازگشت و بهسازی Faromid

**مبنا:** `faromid-nextjs(3).zip`

## تغییرات

- محتوای تبلیغاتی افزوده‌شده در Hero نسخه‌های جدید حذف شد. Hero اکنون بنری با تصویر `assets/home/8b06cc...webp` و SVG اصلی `assets/ui/hero-stripes.svg` است. فقط انیمیشن CSS با رعایت `prefers-reduced-motion` اضافه شده.
- کدهای ShapeWaves و وابستگی `vgpu` حذف شدند.
- طراحی قدیمی `1728 × N` و توده JSX مطلقِ دسکتاپ به بخش‌های مستقل و واکنش‌گرا تغییر کرد.
- منو از حالت کنترل‌های هم‌پوشان به Navbar واحد و منوی موبایل تبدیل شد.
- Carousel با CSS scroll snap بازسازی شد: کنترل صفحه با دکمه‌های قبلی/بعدی، نوار وضعیت، اسکرول لمسی و کیبورد.
- دکمه‌های شناور تکراری حذف و Hoverهای قرمز شدید با سایه و جابه‌جایی ملایم جایگزین شد.
- همه صفحه‌ها از تصاویر محلی پیشین استفاده می‌کنند؛ صفحه تماس از تصویر نقشه اصلی استفاده می‌کند.
- متن‌های کلیدی صفحات از نسخه آپلودشده گرفته شده و محتوای تبلیغاتی اضافی ساخته نشده است.

## تضمین دارایی‌های تصویری

در `scripts/original-assets-sha256.json` اثرانگشت SHA256 تمام ۸۳ فایل اصلی قرار دارد. `npm run verify:assets` فایل‌ها را بایت‌به‌بایت با مبنا مقایسه می‌کند. این تضمین درباره **فایل‌ها**ست، نه مکان نمایش یکسان عناصر طراحی قدیمی؛ چون چیدمان بنا به درخواست به Grid/Flex تغییر کرده است.

## تست‌ها

- `npm run verify:design-free`
- `npm run verify:source`
- `npm run verify:assets`
- بررسی پارس TSX در صورت در دسترس بودن TypeScript
- **تست نهایی Next.js و Web Browser:** وابسته به نصب موفق NPM؛ اگر نصب در این محیط در دسترس نباشد باید پس از استخراج ZIP روی دستگاه توسعه‌دهنده انجام شود.

## محدودیت‌ها

- فرم‌های تماس از `mailto:` استفاده می‌کنند و API سمت سرور ندارند.
- نمایش نقشه به لینک سرویس نقشه خارجی ارجاع می‌دهد، اما تصویر نقشه در سایت محلی است.
- به علت معماری Responsive جدید، موقعیت پیکسلی تمام اجزای Artboard سابق الزاماً ثابت نمانده است.
